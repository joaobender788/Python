1. Importações e Inicialização
No topo, o script importa as bibliotecas necessárias:

pandas e numpy para manipulação de tabelas e matrizes.
sklearn (Scikit-Learn) para divisão dos dados, normalização, algoritmos de IA, otimização e métricas.
imblearn para balanceamento de dados.
pickle (dump) para salvar o modelo final em um arquivo.

2. Carregamento dos Dados e Separação
Python
dados = pd.read_csv('diabetes.csv')
dados_atributos = dados.drop(columns=['Outcome'])
dados_classe = dados['Outcome']
O código lê o arquivo diabetes.csv.

Em seguida, ele separa o alvo (a coluna Outcome, que diz se a pessoa tem ou não diabetes) dos atributos previsores 
(idade, pressão, glicose, etc.).

dados_atributos armazena as características físicas dos pacientes.
dados_classe armazena o gabarito (0 para não diabético, 1 para diabético).

3. Balanceamento de Dados com SMOTE
Python
resampler = SMOTE(random_state=42)
atributos_b, classes_b = resampler.fit_resample(dados_atributos, dados_classe)
Bases de dados médicas costumam ser desbalanceadas (ex: muito mais pessoas saudáveis do que doentes). 
Se o modelo treinar assim, ele fica "viciado" em dizer que ninguém está doente.

O SMOTE resolve isso criando dados sintéticos (artificiais, mas estatisticamente válidos) da classe minoritária até que ambas as classes 
fiquem com a mesma quantidade de registros.

4. Divisão em Treino e Teste
Python
atributos_train, atributos_teste, classe_train, classe_test = train_test_split(
    atributos_b, classes_b, test_size=0.3, random_state=42
)
Os dados são divididos de forma que 70% vão para o algoritmo estudar (train) e 30% ficam guardados em segredo para testar o modelo 
depois (test). O random_state=42 serve apenas como uma semente aleatória para garantir que essa divisão seja sempre igual toda vez que 
você rodar o código.

5. Pré-processamento: Normalização (Escalonamento)
Python
scaler = StandardScaler()
atributos_train_scaled = scaler.fit_transform(atributos_train)
atributos_teste_scaled = scaler.transform(atributos_teste)
Alguns atributos têm escalas muito diferentes (ex: Glicose pode ser 180, enquanto o histórico familiar é 0.5). O StandardScaler 
reescala todos os dados para que a média seja 0 e o desvio padrão seja 1.

Importante: O fit_transform aprende as regras de escala com os dados de treino. Os dados de teste recebem apenas o transform para 
não causar vazamento de dados (data leakage).

6. Otimização de Hiperparâmetros (O "Coração" do Script)
Nesta etapa, o código cria um dicionário de configurações (grades) para três algoritmos diferentes e usa o RandomizedSearchCV. 
Esse comando testa 10 combinações aleatórias dessas configurações usando Validação Cruzada (cv=3) (dividindo o treino interno em 
3 partes para garantir que o resultado seja robusto).

O script faz isso para:

Random Forest: Ajusta o número de árvores (n_estimators), a profundidade máxima (max_depth), etc.
SVM (Support Vector Machine): Ajusta a margem de erro (C) e o tipo de cálculo (kernel).
Gradient Boosting: Ajusta a velocidade de aprendizado (learning_rate) e tamanho das árvores.
Ao final de cada bloco, o .best_estimator_ extrai a melhor versão configurada de cada modelo (best_rf, best_svm, best_gb).

7. Avaliação e Seleção Automática para Produção
Python
for nome, modelo in modelos.items():
    pred = modelo.predict(atributos_teste_scaled)
    acuracia = accuracy_score(classe_test, pred)
    tn, fp, fn, tp = confusion_matrix(classe_test, pred).ravel()
    ...
O script coloca os 3 melhores modelos para prever os dados de teste (que estavam guardados) e calcula três métricas essenciais 
para a medicina:

Acurácia: O percentual total de acertos.
Sensibilidade (Recall): A capacidade do modelo de detectar pessoas doentes (evita falsos negativos).
Especificidade: A capacidade de detectar pessoas saudáveis (evita falsos positivos).

Em seguida, esta linha mágica faz a escolha automatizada:

Python
melhor_nome = max(resultados, key=lambda k: resultados[k]['Acuracia'])
Ela varre o dicionário de resultados e descobre qual algoritmo teve a maior Acurácia geral.

8. Salvando os Arquivos Finais
Python
dump(melhor_modelo_objeto, open('melhor_modelo_producao.pkl', 'wb'))
dump(scaler, open('scaler_diabetes.pkl', 'wb'))
Por fim, o script salva o modelo vencedor e o objeto scaler (responsável por normalizar os dados) em arquivos .pkl (arquivos Pickle).

Por que isso é feito? Para que, em um sistema web ou aplicativo real, você não precise treinar tudo de novo. O sistema final só precisará abrir esses arquivos prontos, receber os dados de um novo paciente, normalizá-los com o scaler_diabetes.pkl e fazer a previsão imediata com o melhor_modelo_producao.pkl
